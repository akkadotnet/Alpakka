# AMQP 1.0

AMQP 1.0 source and sink stages for an AMQP.Net Lite client.

Install [Akka.Streams.Amqp.V1](https://www.nuget.org/packages/Akka.Streams.Amqp.V1). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/Amqp/Akka.Streams.Amqp.V1/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
