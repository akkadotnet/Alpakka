# Amazon SQS

Amazon SQS publishing and receiving stages with explicit message actions.

Install [Akka.Streams.SQS](https://www.nuget.org/packages/Akka.Streams.SQS). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/AWS/SQS/Akka.Streams.SQS/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
