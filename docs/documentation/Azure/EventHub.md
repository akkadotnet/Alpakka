# Azure Event Hubs

Azure.Messaging.EventHubs sources and sinks with processor and checkpoint integration.

Install [Akka.Streams.Azure.EventHub](https://www.nuget.org/packages/Akka.Streams.Azure.EventHub). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/Azure/Akka.Streams.Azure.EventHub/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
