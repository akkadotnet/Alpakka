# Azure Service Bus

Azure.Messaging.ServiceBus queue and topic sources and sinks.

Install [Akka.Streams.Azure.ServiceBus](https://www.nuget.org/packages/Akka.Streams.Azure.ServiceBus). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/Azure/Akka.Streams.Azure.ServiceBus/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
