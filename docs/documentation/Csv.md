# CSV

Byte-oriented CSV parsing, formatting and header/mapping stages.

Install [Akka.Streams.Csv](https://www.nuget.org/packages/Akka.Streams.Csv). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/Csv/Akka.Streams.Csv/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
