# File

Filesystem change notifications and sinks that rotate between files or other child sinks.

Install [Akka.Streams.File](https://www.nuget.org/packages/Akka.Streams.File). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/File/Akka.Streams.File/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
