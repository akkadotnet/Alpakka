# SignalR

ASP.NET Core SignalR integration through typed hubs, shared connector streams and client routing. This package targets .NET 6.0; it does not implement the old OWIN PersistentConnection API.

Install [Akka.Streams.SignalR](https://www.nuget.org/packages/Akka.Streams.SignalR). The [package README](https://github.com/akkadotnet/Alpakka/blob/dev/src/SignalR/Akka.Streams.SignalR/README.md) contains the maintained usage examples, materialized values, defaults, ownership rules and known limits. Packages built from current source include that README; older published releases may omit it.

See [local test instructions](https://github.com/akkadotnet/Alpakka/blob/dev/docs/community/Testing.md) for the service boundary and platform coverage.
